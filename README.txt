פרויקט פאנל בחירות לכנסת ה-26
==============================

כדי להפעיל את השרת (Backend):
1. פתח טרמינל בתיקיית backend
2. הרץ את הפקודה: npm install
3. הרץ את הפקודה: npm start

כדי להפעיל את צד הלקוח (Frontend - React):
1. פתח טרמינל נוסף בתיקיית frontend
2. הרץ את הפקודה: npm install
3. הרץ את הפקודה: npm run dev
